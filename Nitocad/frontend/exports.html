Exports

Generate a part once, then download it in the format your next tool needs. STEP, IGES, DXF, PDF and STL are all included.

STEP

True CAD solids for manufacturing, ready to open in SolidWorks, Fusion 360 or Inventor.

IGES

Solid models for CAD and CAM tools that still expect the IGES format.

DXF

2D vector drawings for laser cutting, CNC and shop-floor drawings.

PDF

Engineering drawings with dimensions, for review and sign-off.

STL

Lightweight mesh for 3D printing and for the free preview.

Each format is built when you ask for it. It is included with the part you generated, so no format is billed again.
