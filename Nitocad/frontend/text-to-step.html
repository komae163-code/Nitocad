Generate a STEP file from a text description

STEP is the standard file format for exchanging exact 3D geometry between CAD and CAM systems. With NitoCAD you describe a part in plain English, check a free preview, then generate the STEP file in CAD Studio.

Steps

  1. Describe the part. Give the shape, the dimensions with units and what it must do. For example: "L-bracket, 100 mm long, 60 mm wide, 40 mm high, 3 mm wall, two 8 mm holes, under 200 g." This is an example prompt.
  2. Look at the free preview. The preview is an STL mesh and needs no wallet. Change the description until the shape is right.
  3. Sign in to CAD Studio. Keep refining in the same chat, then generate the files.
  4. Download the STEP file. IGES, DXF, PDF, STL, GLB, 3MF and URDF are available too.
  5. Open it in your CAD or CAM tool and confirm the dimensions before you manufacture.

What is inside the file

NitoCAD builds a B-rep solid on OpenCASCADE, so the STEP file holds exact surfaces and edges rather than triangles. Other CAD tools can select faces, measure edges and use the part in an assembly. Why that matters.

Tips for better results

  • State units and every dimension that matters. NitoCAD keeps your numbers exactly as written.
  • Add requirements such as envelope, mass, wall thickness or material, so each version is checked against them. How verification works.
  • Attach a STEP file, DXF or sketch when you are starting from something that exists.

The file is a starting point for engineering work, not a certified design. Check dimensions before you manufacture.
