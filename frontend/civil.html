Civil tools

Surface from survey points, alignments, earthworks quantities, drainage and retaining wall checks. SI units.

Screening level only. These are textbook calculations for early sizing. Results are not a design, and a pass here is not compliance with any standard. A licensed engineer must verify anything that gets built.
Criteria used for the pass and fail checks

These limits are yours to set. The starting values are generic round numbers, not any country's standard. Edit the JSON to match the standard your project follows. Set a field to null to skip that check.

Survey points

One point per line. Use a header row (for example id,easting,northing,elevation) or just x,y,z. Commas, tabs, semicolons and spaces all work.

Alignment

Uses the survey points from the first tab. Horizontal: one PI per line as x,y,radius (radius 0 for a sharp corner). Vertical: one PVI per line as station,elevation,curve length.
